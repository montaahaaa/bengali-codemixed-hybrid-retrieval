# How to review (about 1 minute per row)
For each row read the passage, then the three questions (Bangla, mixed, Romanized). Fill the yes/no columns:
- **natural**: would a real person in Bangladesh write this? (Romanized: informal chat spelling is fine.)
- **answerable**: does THIS passage contain the answer?
- **same_meaning_all_three**: do the three questions ask the same thing?
- **fix_or_notes**: if no, write the corrected question or why.
Rows with double_review = yes are rated by two people independently (do not look at each other's sheet).
Use only yes or no. Put your initials in `reviewer`.
